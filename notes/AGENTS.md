# 專案名稱：中央電機生存指南 (EE Survival Guide)

## 1. 專案目的
建立一個結構化、易於擴充的電機系核心考科（電磁學、電路學、微電子學等）靜態網頁筆記本。透過規範化的架構，讓 AI 助理能快速生成排版一致的新章節筆記。

## 2. 檔案結構與命名規則
- `index.html`：網站首頁（目錄導覽）。
- `css/style.css`：全站共用樣式表。
- `notes/`：存放所有筆記頁面的資料夾。
  - 命名格式：`[科目英文縮寫]-[章節數字].html` (全部小寫)。
  - 範例：`em-ch1.html` (電磁學第一章)、`circuit-ch2.html` (電路學第二章)。

## 3. 網頁整體風格
- **極簡學術風**：背景使用淺灰白 (`#f8f9fa`)，文字使用深灰 (`#333333`)，確保長時間閱讀的舒適度。
- **數學公式支援**：所有筆記頁面必須在 `<head>` 引入 MathJax 腳本以渲染 LaTeX 公式。
- **排版層級**：標題使用藍色系 (`#0056b3`) 區隔，程式碼或解題步驟區塊需有淺灰色背景與圓角。

## 4. 新增內容格式規範 (HTML 骨架)
當接收到指令要「新增一個筆記頁面」時，AI 必須使用以下 HTML 結構：
1. 包含一個 `<header>` 顯示網站標題與返回首頁的 `<a>` 連結。
2. 內容放在 `<main class="note-container">` 中。
3. 筆記內容必須包含：
   - `<h1>`：章節標題
   - `<h2>`：核心概念子標題
   - `<div class="formula-box">`：用來放置重要公式的區塊
   - `<div class="example-box">`：用來放置例題與推導步驟的區塊

## 5. AI 開發與修改規則
- **絕對遵守格式**：不可隨意更改 CSS class 名稱，必須使用 `formula-box` 與 `example-box`。
- **更新首頁目錄**：每次在 `notes/` 建立新頁面後，必須主動提醒使用者將新連結補充至 `index.html` 的目錄區塊中。
- **嚴謹的推導**：處理微積分、複變函數或電路方程式時，務必一步步寫出推導過程，不可跳躍。若公式有變數，需在下方加上清單解釋變數意義。
